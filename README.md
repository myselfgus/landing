# Landing Page

Uma landing page moderna e responsiva com integração de IA.

## 🚀 Visão Geral

Landing page desenvolvida para apresentar conteúdo de forma elegante e eficaz, com foco em performance e experiência do usuário.

## ✨ Características

- Design responsivo e mobile-first
- Otimização de performance
- SEO-friendly
- Interface moderna e minimalista
- Integração com Gemini AI

## 🛠️ Tecnologias Utilizadas

- **Frontend**: Next.js / React
- **Estilização**: CSS Modules / Tailwind CSS
- **API**: Gemini AI
- **Deploy**: Vercel / AI Studio

## 📦 Como Executar

### Pré-requisitos

- Node.js (v18 ou superior)
- npm ou yarn
- Chave de API do Gemini

### Instalação

1. **Clone o repositório**
   ```bash
   git clone https://github.com/myselfgus/landing.git
   cd landing
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Configure as variáveis de ambiente**
   
   Crie um arquivo `.env.local` na raiz do projeto:
   ```env
   GEMINI_API_KEY=sua_api_key_aqui
   ```

4. **Execute o projeto**
   ```bash
   npm run dev
   ```

5. **Acesse no navegador**
   ```
   http://localhost:3000
   ```
